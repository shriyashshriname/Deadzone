# Research Sources and Verification Notes

Research snapshot: 16 November 2026.

## Sumiro

## Antigravity
- Models: https://antigravity.google/docs/models
- Custom subagents: https://antigravity.google/docs/subagents/

Current docs list custom workspace agent files under `.agents/agents/`. Agent orchestration options and model entitlements can change. Check the live account selector and CLI.

## Jio
- Official offer FAQ: https://www.jio.com/help/faq/mobile/offers/google-gemini-offer/
- Offer terms: https://www.jio.com/jcms/en-in/jio-google-gemini-terms-and-conditions/

The official FAQ currently says the offer is no longer available to newly claiming users; previously claimed users can continue under eligibility terms.

## Unity
- Plans: https://unity.com/products
- License compliance: https://unity.com/pages/license-compliance

Unity Personal currently has a US$200,000 recent-12-month financial threshold. Re-check current eligibility.

## Google Play
- Account setup and US$25 registration: https://support.google.com/googleplay/android-developer/answer/6112435
- New personal account closed testing: https://support.google.com/googleplay/android-developer/answer/14151465

New personal developer accounts created after 13 November 2023 need 12 testers opted in continuously for 14 days before applying for production access.

## Apple
- Developer Program membership: https://developer.apple.com/help/account/membership/program-enrollment
- App Review Guidelines: https://developer.apple.com/app-store/review/guidelines/
- Unity iOS environment setup: https://docs.unity3d.com/2023.2/Documentation/Manual/ios-environment-setup.html

Apple Developer Program membership is US$99/year. Local iOS build/signing requires Xcode on macOS. Confirm current versions and regional fees before submission.
