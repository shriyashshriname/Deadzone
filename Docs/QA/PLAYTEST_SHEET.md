# DEADZONE — Gate 4 External Playtest Feedback Protocol

**Target Session Duration:** 8 to 10 minutes per tester  
**Test Build Target:** Standalone Windows x64 / Android Development Build  
**Audience:** Outside players (independent testers who did not build the game)  
**Gate 4 Success Threshold:** Minimum 3 of 5 outside testers answering **YES** to playing another run.
