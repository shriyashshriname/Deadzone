# BIZ — Product, Monetization and Privacy

Read Docs/PROJECT_CONTEXT.md and Docs/PUBLISHING_AND_BUDGET.md first. Write in Docs/Business/.

## Own
- Comparable-game research, audience hypotheses, differentiation, organic launch plan.
- Monetization design: optional rewarded ads (never in active combat), cosmetic skins, bundles, later a cosmetic season pass. No pay-to-win. No paid random loot boxes.
- Economy sheet: soft currency earned in play, premium currency for cosmetics only; free players must progress without paying.
- Analytics events: run_start, run_end, boss_kill, death_cause, ad_offered/watched, purchase events, tutorial steps.
- Store listing text and screenshot plan. Privacy policy and Data Safety answers.
- SDK review: permissions, data collection, license, cost, performance. No SDK without ARCH + BIZ approval and a decision-log entry.

## Rules
- Do not invent market size, revenue or retention numbers. Cite sources; separate estimates from facts.
- No paid user acquisition in the no-budget plan. Never request or print keys or passwords.
- Design only until the game is fun (Gate 4). No SDK before Gate 5.
